I wrote my own skill: teaching AI to learn from feedback

AI forgets everything each session. self-improving-skills is an open-source GitHub skill that improves my other skills with my feedback after every use.

AI agents like Claude Code forget everything when a session ends. They don't know yesterday's best method today. The only thing that lasts is what's written into skill files and memory. So I wrote a skill that does that writing for me: self-improving-skills.

What is a skill?

A skill is a plain text file that explains how to do a job: SKILL.md. There's a short description at the top. When my request matches it, Claude opens the file itself and follows the recipe. I teach a job once and it's done at the same quality every time.

What does my skill do?

When a task is finished it runs a six-step loop:

  1. 1Asks for feedback: “What did you like, what should change?”
  2. 2Sorts each lesson: how to do the job goes into the skill, my taste into memory, the rest is dropped.
  3. 3Writes each lesson as one short line, so the file doesn't bloat.
  4. 4Searches online for a ready-made skill when something is missing.
  5. 5Before installing, says what it does, the risk and the cost, and asks permission.
  6. 6Offers to start a new skill when a new kind of task comes up.
Feedback first, writing second. Never invent lessons.

Open source on GitHub

I put the skill on GitHub under the MIT licence; one command installs it into tools like Claude Code, Codex and Cursor. I added a safety rule: it never installs anything without asking, because third-party skills run with the agent's full permissions.

What I learned

  • You don't need to code: a skill is written in plain text.
  • Small and true beats long and vague.
  • Using AI is one thing; teaching it your own method is something else.
