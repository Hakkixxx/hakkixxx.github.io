My first Python automation: renaming 40 files in seconds

I applied the loops from class to a boring chore. Full code, a step-by-step walkthrough and the real output.

When a folder is full of meaningless names like IMG_a7f3.png, renaming them scene-01, scene-02 by hand is tedious. I realised the for loop from class could shrink the job to a few lines.

The whole code

Step by step

  1. 1I point Path at the folder.
  2. 2glob picks only the .png files and I sort them.
  3. 3enumerate gives each file a number starting at 1.
  4. 4{i:02} pads the number to two digits: 01 instead of 1.
  5. 5rename changes the file's name.
The moment programming really clicked: when I watched code do the boring job for me.
